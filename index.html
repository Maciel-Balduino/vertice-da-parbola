Como encontrar o vértice?

Uma função quadrática tem a forma f(x) = ax² + bx + c, com a ≠ 0.

1. Calcule Δ = b² − 4ac.

2. Calcule xᵥ = −b/(2a).

3. Calcule yᵥ = −Δ/(4a), ou substitua xᵥ em f(x).

O vértice é V = (xᵥ, yᵥ). Se a > 0, ele é um ponto de mínimo; se a < 0, é um ponto de máximo. O eixo de simetria é x = xᵥ.

Exemplo

f(x) = x² − 4x + 3. Δ = 16 − 12 = 4. Logo xᵥ = 4/2 = 2 e yᵥ = −4/4 = −1. Portanto V = (2, −1).
